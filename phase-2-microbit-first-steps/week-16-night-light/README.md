# Week 16 · Night-Light Robot

**Phase 2: micro:bit First Steps** · ~45 min build + short play sessions during the week · **Skill:** Light sensor

## You need

- micro:bit + battery pack
- Cardboard robot with a window

## Build together

1. Flash the code. The LED screen is also a light sensor.
2. Cover it with a hand: the robot lights up.

## Play

Peekaboo: cover the robot's eyes to wake it up, uncover to put it to sleep.

## Talk about it

> How can the same LEDs show light AND measure it?

## Level up

Change how dark it must be before the robot wakes up.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → switch to **JavaScript** → paste the file → **Download** and copy to the MICROBIT drive. Switch back to **Blocks** to show your kid the colorful version.
