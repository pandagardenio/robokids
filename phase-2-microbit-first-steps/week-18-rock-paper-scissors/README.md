# Week 18 · Rock, Paper, Scissors

**Phase 2: micro:bit First Steps** · ~45 min build + short play sessions during the week · **Skill:** Random choice and if/else

## You need

- micro:bit + battery pack

## Build together

1. Flash the code. Shake to make the robot choose.

## Play

Play against the robot. Keep score on paper for the week.

## Talk about it

> Can you predict what the robot will choose?

## Level up

Add a fourth choice (lizard? spock?).

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → switch to **JavaScript** → paste the file → **Download** and copy to the MICROBIT drive. Switch back to **Blocks** to show your kid the colorful version.

## Robot Journal

Draw this week's robot. Write (or dictate) one thing it can do.
