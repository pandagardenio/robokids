# Week 18 · Rock, Paper, Scissors

**Phase 2: micro:bit First Steps** · ~45 min build + short play sessions during the week · **Skill:** Random choice and if/else

## You need

- micro:bit + battery pack

## Build together

1. Load this week's program (steps below). Shake to make the robot choose.

## Play

Play against the robot. Keep score on paper for the week.

## Talk about it

> Can you predict what the robot will choose?

## Level up

Add a fourth choice (lizard? spock?).

## Load the program

Program: [`main.ts`](main.ts)

1. Click the program link, then the **Copy raw file** button (two small squares, top right of the program).
2. Go to [makecode.microbit.org](https://makecode.microbit.org), click **New Project** and name it `Week 18`.
3. Click **JavaScript** at the top, select all the text (**Ctrl+A**, Mac: **Cmd+A**) and paste (**Ctrl+V**, Mac: **Cmd+V**).
4. Click **Blocks** to see the colorful version your kid can change, then click **Download**.

First time, or something went wrong? See [Start here](../../START-HERE.md#load-a-program).

## Robot Journal

Draw this week's robot. Write (or dictate) one thing it can do.
