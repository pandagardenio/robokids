# Week 17 · Robot Music Box

**Phase 2: micro:bit First Steps** · ~45 min build + short play sessions during the week · **Skill:** Sound and sequences

## You need

- micro:bit V2 (has a speaker)

## Build together

1. Flash the code. A plays a built-in melody, B plays the kid's own tune.

## Play

Kid composes a 6-note tune with you (edit the notes in the code). Play it to the family.

## Talk about it

> What happens if you change the order of the notes?

## Level up

Make the robot play a different tune when shaken.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → switch to **JavaScript** → paste the file → **Download** and copy to the MICROBIT drive. Switch back to **Blocks** to show your kid the colorful version.

Draw this week's robot. Write (or dictate) one thing it can do.
