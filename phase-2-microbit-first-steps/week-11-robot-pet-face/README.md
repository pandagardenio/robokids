# Week 11 · Robot Pet Face

**Phase 2: micro:bit First Steps** · ~45 min build + short play sessions during the week · **Skill:** Inputs and outputs

## You need

- BBC micro:bit V2 + USB cable
- Battery pack (2×AAA)
- Cardboard pet body

## Build together

1. Plug in the micro:bit and load this week's program (steps below).
2. Build a cardboard pet with a window for the LED screen.

## Play

Button A = happy, B = sad, A+B = surprised, shake = dizzy. Kid decides what each one means for the pet.

## Talk about it

> What are the pet's inputs? What are its outputs?

## Level up

Change the icons. Draw your own face with the LED editor.

## Load the program

Program: [`main.ts`](main.ts)

1. Click the program link, then the **Copy raw file** button (two small squares, top right of the program).
2. Go to [makecode.microbit.org](https://makecode.microbit.org), click **New Project** and name it `Week 11`.
3. Click **JavaScript** at the top, select all the text (**Ctrl+A**, Mac: **Cmd+A**) and paste (**Ctrl+V**, Mac: **Cmd+V**).
4. Click **Blocks** to see the colorful version your kid can change, then click **Download**.

First time, or something went wrong? See [Start here](../../START-HERE.md#load-a-program).
