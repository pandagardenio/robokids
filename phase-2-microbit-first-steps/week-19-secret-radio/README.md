# Week 19 · Secret Radio Messages

**Phase 2: micro:bit First Steps** · ~45 min build + short play sessions during the week · **Skill:** Radio communication

## You need

- 2 micro:bits (borrow one or buy a second)
- 2 battery packs

## Build together

1. Flash the same code to both.
2.  A sends a heart, B sends a smiley, shake sends a skull for 'danger'.

## Play

Spy game: one person hides in another room. Agree on a code (heart = 'come here', smiley = 'all good').

## Talk about it

> How did the message get there with no wire?

## Level up

Change the radio group number so nobody else can listen.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → switch to **JavaScript** → paste the file → **Download** and copy to the MICROBIT drive. Switch back to **Blocks** to show your kid the colorful version.
