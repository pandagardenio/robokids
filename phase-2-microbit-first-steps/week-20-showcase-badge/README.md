# Week 20 · Showcase: Robot Badge

**Phase 2: micro:bit First Steps** · ~45 min build + short play sessions during the week · **Skill:** Review

## You need

- micro:bit + battery pack
- Lanyard or safety pin + cardboard holder

## Build together

1. Combine favorite features: name scroll, pet face, dice.

## Play

Kid wears the badge for a day and demos it to everyone they meet.

## Talk about it

> Which feature do people like most?

## Level up

Add their own idea to the badge.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → switch to **JavaScript** → paste the file → **Download** and copy to the MICROBIT drive. Switch back to **Blocks** to show your kid the colorful version.

## Robot Journal

Draw this week's robot. Write (or dictate) one thing it can do.
