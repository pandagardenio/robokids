# Week 12 · Shake Dice

**Phase 2: micro:bit First Steps** · ~45 min build + short play sessions during the week · **Skill:** Random numbers and the accelerometer

## You need

- micro:bit + battery pack

## Build together

1. Flash the code. Shake to roll 1–6.

## Play

Use the dice for your favorite board game for the whole week.

## Talk about it

> How does the micro:bit know it was shaken?

## Level up

Make a 1–20 dice, or a dice that shows arrows for the next week's robot car game.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → switch to **JavaScript** → paste the file → **Download** and copy to the MICROBIT drive. Switch back to **Blocks** to show your kid the colorful version.

Draw this week's robot. Write (or dictate) one thing it can do.
