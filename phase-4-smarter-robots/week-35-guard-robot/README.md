# Week 35 · Guard Robot

**Phase 4: Smarter Robots** · ~45 min build + short play sessions during the week · **Skill:** Alarms and states

## You need

- Robot car
- A treasure (toy) to guard

## Build together

1. Flash the code. Press A to arm. If something comes within 30 cm, alarm lights and sound.

## Play

Sneak-up game: try to steal the treasure without triggering the guard.

## Talk about it

> What does 'armed' mean for the robot?

## Level up

Make the guard turn toward the thief before sounding.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.
