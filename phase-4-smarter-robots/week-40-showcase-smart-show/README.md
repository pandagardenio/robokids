# Week 40 · Showcase: Smart Robot Show

**Phase 4: Smarter Robots** · ~45 min build + short play sessions during the week · **Skill:** Review

## You need

- Robot car
- Props from weeks 31–39

## Build together

1. Kid picks three favorite behaviors. Flash the combined show program.

## Play

Ticketed show for the family (paper tickets, popcorn).

## Talk about it

> If you could add one more sensor, what would it be?

## Level up

Kid presents and explains one behavior in their own words.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.

## Robot Journal

Draw this week's robot. Write (or dictate) one thing it can do.
