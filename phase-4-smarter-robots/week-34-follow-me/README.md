# Week 34 · Follow-Me Robot

**Phase 4: Smarter Robots** · ~45 min build + short play sessions during the week · **Skill:** Keeping distance

## You need

- Robot car
- A flat book as the 'leader'

## Build together

1. Flash the code. The robot tries to stay about 20 cm from the book.

## Play

Walk the robot like a puppy around the room.

## Talk about it

> What does the robot do if you come too close?

## Level up

Change 20 cm to 40 cm: a shy puppy.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.
