# Week 32 · Bulldozer

**Phase 4: Smarter Robots** · ~45 min build + short play sessions during the week · **Skill:** Pushing and power

## You need

- Robot car
- Cardboard plow taped to the front
- Duplo or foam blocks

## Build together

1. Flash the code. The bulldozer pushes forward until it sees a wall, then backs up.

## Play

Clean-up time: push blocks into a 'garage' (shoebox on its side).

## Talk about it

> Is the robot faster pushing or not pushing? Why?

## Level up

Use the servo arm as a scoop.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.

## Robot Journal

Draw this week's robot. Write (or dictate) one thing it can do.
