# Week 37 · Hot and Cold Treasure Hunt

**Phase 4: Smarter Robots** · ~45 min build + short play sessions during the week · **Skill:** Signal strength

## You need

- 2 micro:bits (one hidden as the 'treasure beacon')
- Battery packs

## Build together

1. Flash `beacon.ts` to the hidden micro:bit and `main.ts` to the seeker (car or handheld).

## Play

Hide the beacon. The seeker's screen fills up the closer it gets. Find it!

## Talk about it

> Why does the signal get stronger as you get closer?

## Level up

Hide it inside a metal pot. What happens?

## Code

[`main.ts`](main.ts), [`beacon.ts`](beacon.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.

## Robot Journal

Draw this week's robot. Write (or dictate) one thing it can do.
