# Week 33 · Clap-Activated Robot

**Phase 4: Smarter Robots** · ~45 min build + short play sessions during the week · **Skill:** Sound sensor

## You need

- Robot car with micro:bit V2 (microphone)

## Build together

1. Flash the code. One loud clap = go / stop. The LED shows how loud the room is.

## Play

Freeze dance with the robot: clap to start and stop.

## Talk about it

> Does the robot hear words or only loudness?

## Level up

Two claps = spin (count claps in a short time window).

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.
