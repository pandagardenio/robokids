# Week 38 · Drawing Robot

**Phase 4: Smarter Robots** · ~45 min build + short play sessions during the week · **Skill:** Geometry with code

## You need

- Robot car
- Felt-tip marker taped to the back center
- Large paper

## Build together

1. Flash the code. A = square, B = triangle, A+B = flower (loop of loops).

## Play

Make an art gallery of robot drawings.

## Talk about it

> How many turns make a full circle?

## Level up

Write their initial with the robot.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.

## Robot Journal

Draw this week's robot. Write (or dictate) one thing it can do.
