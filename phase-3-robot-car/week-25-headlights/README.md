# Week 25 · Disco Headlights

**Phase 3: The Robot Car** · ~45 min build + short play sessions during the week · **Skill:** Colors and RGB

## You need

- Robot car
- Dark room

## Build together

1. Flash the code. Each button press changes the headlight color.

## Play

Disco: robot flashes colors to music while dancing.

## Talk about it

> How can three colors (red, green, blue) make all the others?

## Level up

Choose colors for 'happy', 'angry' and 'sleepy'.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.
