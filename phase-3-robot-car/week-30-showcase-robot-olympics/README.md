# Week 30 · Showcase: Robot Olympics

**Phase 3: The Robot Car** · ~45 min build + short play sessions during the week · **Skill:** Review

## You need

- Robot car
- Track, maze, parking spot from earlier weeks
- Bottle-cap medals

## Build together

1. Flash the menu program: A cycles through events, B starts.

## Play

Three events: line race (timed), maze escape, parking. Family is the jury.

## Talk about it

> Which event was hardest for the robot?

## Level up

Invent a fourth event.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.

Draw this week's robot. Write (or dictate) one thing it can do.
