# Week 26 · Line Follower

**Phase 3: The Robot Car** · ~45 min build + short play sessions during the week · **Skill:** Sensors + if/else

## You need

- Robot car
- Black electrical tape (2 cm wide)
- Big white paper or light floor

## Build together

1. Make a closed loop track with gentle curves.
2. Flash the code. Put the robot on the line and press A.

## Play

Kid designs new tracks each day. Add a 'station' where the robot should stop (you can add that in code).

## Talk about it

> How does the robot know it's leaving the line?

## Level up

Make a figure-8 track. Does it still work?

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.

Draw this week's robot. Write (or dictate) one thing it can do.
