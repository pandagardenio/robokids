# Week 22 · Forward, Stop, Back

**Phase 3: The Robot Car** · ~45 min build + short play sessions during the week · **Skill:** Motor speed and time

## You need

- Robot car
- Masking tape for a start and finish line

## Build together

1. Flash the code. A = forward 1 s, B = backward 1 s.

## Play

Parking game: tape a parking spot. Kid changes the time in the code to park exactly.

## Talk about it

> What changes when you make the number bigger?

## Level up

Change the speed instead of the time. Is it the same?

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.
