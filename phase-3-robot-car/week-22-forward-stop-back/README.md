# Week 22 · Forward, Stop, Back

**Phase 3: The Robot Car** · ~45 min build + short play sessions during the week · **Skill:** Motor speed and time

## You need

- Robot car
- Masking tape for a start and finish line

## Build together

1. Load this week's program (steps below). A = forward 1 s, B = backward 1 s.

## Play

Parking game: tape a parking spot. Kid changes the time in the code to park exactly.

## Talk about it

> What changes when you make the number bigger?

## Level up

Change the speed instead of the time. Is it the same?

## Load the program

Program: [`main.ts`](main.ts) · needs the **Cutebot** extension

1. Click the program link, then the **Copy raw file** button (two small squares, top right of the program).
2. Go to [makecode.microbit.org](https://makecode.microbit.org), click **New Project** and name it `Week 22`.
3. Click **Extensions** at the bottom of the block list, search `cutebot` and click **Cutebot**.
4. Click **JavaScript** at the top, select all the text (**Ctrl+A**, Mac: **Cmd+A**) and paste (**Ctrl+V**, Mac: **Cmd+V**).
5. Click **Blocks** to see the colorful version your kid can change, then click **Download**.

First time, or something went wrong? See [Start here](../../START-HERE.md#load-a-program).

## Words this week

| Word | What it means | Say it to your kid |
| --- | --- | --- |
| **Motor speed** | How fast the wheels turn, from 0 (stopped) to 100 (full speed). Negative numbers drive backwards. | How fast the wheels spin. |
| **Timing** | How long the robot waits or does something. In programs it's often in milliseconds: 1000 = 1 second. | How long it waits. |
| **Code** | Another word for the program: the instructions the robot follows. | The robot's instructions. |

Loading words like *micro:bit*, *MakeCode*, *extension* and *Blocks* are in the [Start here word list](../../START-HERE.md#word-list). All words: [glossary](../../GLOSSARY.md).
