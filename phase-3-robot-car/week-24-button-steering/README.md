# Week 24 · Button Steering

**Phase 3: The Robot Car** · ~45 min build + short play sessions during the week · **Skill:** Events

## You need

- Robot car

## Build together

1. Flash the code. A = turn left, B = turn right, A+B = forward, shake = stop.

## Play

Slalom around shoes on the floor.

## Talk about it

> How does the robot know which button was pressed?

## Level up

Add a 'spin' move when you press the logo (V2 touch logo).

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.

Draw this week's robot. Write (or dictate) one thing it can do.
