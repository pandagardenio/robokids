# Week 23 · Square Dance

**Phase 3: The Robot Car** · ~45 min build + short play sessions during the week · **Skill:** Loops

## You need

- Robot car
- Smooth floor

## Build together

1. Flash the code. Press A: the car drives a square using a 'repeat 4' loop.

## Play

Tune the turn time until the square closes perfectly. Then make a triangle (repeat 3).

## Talk about it

> Why use 'repeat 4' instead of writing it four times?

## Level up

Make a star or a dance with music.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.
