# Week 27 · Obstacle Avoider

**Phase 3: The Robot Car** · ~45 min build + short play sessions during the week · **Skill:** Distance sensor

## You need

- Robot car with ultrasonic sensor (included with Cutebot)
- Boxes and books as walls

## Build together

1. Flash the code. The robot drives until something is closer than 15 cm, then backs up and turns.

## Play

Escape the cave: build a box maze and see how long it takes to get out.

## Talk about it

> How does the robot 'see' without eyes? (Like a bat.)

## Level up

Change 15 cm to 30 cm. Is it more careful now?

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.
