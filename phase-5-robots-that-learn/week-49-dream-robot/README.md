# Week 49 · Dream Robot Build

**Phase 5: Robots That Learn** · ~45 min build + short play sessions during the week · **Skill:** Design thinking

## You need

- Everything from the year
- Cardboard, tape, Robot Journal

## Build together

1. Kid draws the dream robot: what it looks like, what it does, which sensors it uses.
2. Build the cardboard body around the car.
3. Start from `main.ts`: a template with slots for button, shake, distance and sound behaviors.

## Play

Rehearse the robot's show for next week.

## Talk about it

> What was easy to build, and what needed a change from the drawing?

## Level up

Add one AI behavior from weeks 42–48.

## Code

[`main.ts`](main.ts)

Open [makecode.microbit.org](https://makecode.microbit.org) → **New Project** → **Extensions** → search `cutebot` and add it → switch to **JavaScript** → paste the file → **Download**. Switch to **Blocks** so your kid can change the numbers.

## Robot Journal

Draw this week's robot. Write (or dictate) one thing it can do.
