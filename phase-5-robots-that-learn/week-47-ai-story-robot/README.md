# Week 47 · AI Story Robot

**Phase 5: Robots That Learn** · ~45 min build + short play sessions during the week · **Skill:** AI helps create

## You need

- Robot car
- Laptop (parent uses an AI assistant)

## Build together

1. Kid invents a hero robot and a problem. Parent asks an AI for a 5-scene bedtime story with one robot action per scene.
2. Edit the `SCENES` list in the code to match: each scene = a move + face + sound.
3. Each A press plays the next scene while you read.

## Play

Bedtime performance: you read, the robot acts.

## Talk about it

> Which ideas came from you, and which from the AI?

## Level up

Kid writes scene 6 alone.

## Load the program

Program: [`main.ts`](main.ts) · needs the **Cutebot** extension

1. Click the program link, then the **Copy raw file** button (two small squares, top right of the program).
2. Go to [makecode.microbit.org](https://makecode.microbit.org), click **New Project** and name it `Week 47`.
3. Click **Extensions** at the bottom of the block list, search `cutebot` and click **Cutebot**.
4. Click **JavaScript** at the top, select all the text (**Ctrl+A**, Mac: **Cmd+A**) and paste (**Ctrl+V**, Mac: **Cmd+V**).
5. Click **Blocks** to see the colorful version your kid can change, then click **Download**.

First time, or something went wrong? See [Start here](../../START-HERE.md#load-a-program).
