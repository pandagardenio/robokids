# Week 41 · Train Your First AI

**Phase 5: Robots That Learn** · ~45 min build + short play sessions during the week · **Skill:** Learning from examples

## You need

- Laptop with webcam and Chrome/Edge
- teachablemachine.withgoogle.com (free)

## Build together

1. Open Teachable Machine → Image Project. Make two classes: `thumbsup` and `thumbsdown`.
2. Kid records ~50 examples of each. Train.
3. Test: the bars show what the AI thinks.

## Play

Trick the AI: half thumbs, gloves, a toy's hand. When does it fail?

## Talk about it

> How did the AI learn without anyone writing rules?

## Level up

Add a third class: `nothing` (empty background). Does it get better?

## Load the program

Nothing to load this week, only training. Keep the model: you'll use it next week.

## Robot Journal

Draw this week's robot. Write (or dictate) one thing it can do.
