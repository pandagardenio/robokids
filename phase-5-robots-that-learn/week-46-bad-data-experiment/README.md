# Week 46 · The Bad Data Experiment

**Phase 5: Robots That Learn** · ~45 min build + short play sessions during the week · **Skill:** Data quality

## You need

- Week 45 setup

## Build together

1. Train a 'bad' model: only 3 photos per class, in the dark, all from one angle.
2. Train a 'good' model: 50+ photos, lights on, many angles.
3. Test both with the same toys.

## Play

Robot quiz: which model wins more rounds? Kid keeps score.

## Talk about it

> Why did the bad robot get confused?

## Level up

Train with only teddies wearing hats. Then show a teddy without a hat.

## Code

[`main.ts`](main.ts)

Flash the file(s) as usual (car files need the `cutebot` extension). Then open [`ai/bridge.html`](../../ai/bridge.html) in Chrome or Edge. Class names in Teachable Machine must match the labels in the code exactly (lowercase).

Keep this micro:bit plugged into the laptop by USB.
