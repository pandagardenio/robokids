# Week 45 · Toy Sorter

**Phase 5: Robots That Learn** · ~45 min build + short play sessions during the week · **Skill:** Categories

## You need

- Laptop + webcam
- 3 kinds of toys (e.g. teddy, car, ball)
- micro:bit by USB

## Build together

1. Train classes `teddy`, `car`, `ball`, `nothing`.
2. Flash `main.ts`. The micro:bit shows an icon and plays a sound for each toy.

## Play

Toy parade: kid shows toys one by one; the robot names them. Then mystery toys it never saw.

## Talk about it

> What does the AI do with a toy it never learned?

## Level up

Add a 4th toy and retrain.

## Code

[`main.ts`](main.ts)

Flash the file(s) as usual (car files need the `cutebot` extension). Then open [`ai/bridge.html`](../../ai/bridge.html) in Chrome or Edge. Class names in Teachable Machine must match the labels in the code exactly (lowercase).

Keep this micro:bit plugged into the laptop by USB.

## Robot Journal

Draw this week's robot. Write (or dictate) one thing it can do.
