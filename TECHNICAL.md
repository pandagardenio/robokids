# Technical notes

For parents who code and contributors. Nothing here is needed to use the project.

## Programs

- All programs are MakeCode **TypeScript** (`.ts`), pasted into the JavaScript view of [MakeCode](https://makecode.microbit.org). They convert to Blocks, so stick to simple statements: avoid classes and complex generics in files the kid will see.
- Tunable numbers (speed, time, distance) sit at the top of each file with a comment: those are the kid's knobs.
- Car programs target the **Elecfreaks Cutebot** (`cutebot` extension) and start with a small *kit adapter* (`drive`, `halt`, `lights`, `distanceCm`). To support another car, change only those functions. The DIY mouse uses the `kitronik-motor-driver` extension.
- If you keep your kid's versions in git, commit after each session: their changes are a nice history of their learning.

## Glossary

Each week's **Words this week** table and [`GLOSSARY.md`](GLOSSARY.md) are generated by [`tools/glossary.py`](tools/glossary.py). After editing a week page or adding a word to the `WORDS` list in that script, run `python3 tools/glossary.py` from the repo root. It only lists a word on a week whose own text mentions it.

## Website and printables

The website in [`web/`](web/) and the printable PDFs in `web/print/` are generated from the Markdown pages and programs. Don't edit `web/` by hand. After changing a page or program, rebuild and commit `web/` together with your change:

```bash
pip install markdown           # once
python3 tools/build_site.py    # rebuilds web/ and checks every local link
node tools/make_pdfs.mjs       # refreshes the PDFs (needs Playwright with Chromium)
```

- [`tools/build_site.py`](tools/build_site.py) renders the pages; `.md` links become site links, `.ts` links jump to the program shown inline with a Copy button. Styles, script and fonts live in [`tools/site/`](tools/site/).
- Printables (`web/print/*.html`) are sized to fit both A4 and US Letter; `make_pdfs.mjs` saves each one in both sizes.
- The site keeps ticked weeks and journal drawings in the browser's `localStorage` only. It loads nothing from other websites (fonts are self-hosted, SIL Open Font License).
- GitHub Pages serves the repo root; the root `index.html` redirects to `web/`.

## AI bridge

[`ai/bridge.html`](ai/bridge.html) is a single static page served by GitHub Pages (the repo root has `.nojekyll`). It loads Teachable Machine models with TensorFlow.js and talks to the micro:bit over Web Serial (Chrome and Edge only).

- Bridge → micro:bit: the winning class label plus `\n`, sent only when it changes. If confidence is below the slider, it sends `unsure`.
- micro:bit → bridge: any line starting with `say:` is spoken aloud by the browser (week 48). Other lines are shown in the log.
- Baud rate: 115200. USB vendor ID filter: `0x0d28`.
- To run it locally, serve the repo (`python3 -m http.server`) and open `http://localhost:8000/ai/bridge.html`.

## Linux USB access

WebUSB (MakeCode's "Connect device") and Web Serial (the bridge) need a udev rule for vendor `0d28`. [START-HERE.md](START-HERE.md#linux-only-allow-the-microbit) has the copy-paste version.
