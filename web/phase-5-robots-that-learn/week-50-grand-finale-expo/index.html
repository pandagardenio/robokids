🧠 Phase 5 · Robots That Learn 🎉 Showcase week

Week 50 Grand Finale: Robot Expo

⏱️ ~45 min build + short play sessions during the week 🎯 Skill: Celebrate the year

🧰 You need

  • Favorite robots from all phases
  • Certificate (see certificate.md)
  • Family audience

🔧 Build together Together

  1. Set up three stations: a Phase 1 robot, a micro:bit project, and the dream robot.
  2. Kid prepares one sentence per robot.

🎮 Play Kid time

Robot Expo! Kid presents, family asks questions. Hand over the certificate.

💬 Talk about it Together

What do you want to build next year?

⭐ Level up Kid time

Pick a project to keep improving in year 2.

✏️ Robot Journal Kid time

Draw this week's robot. Write (or dictate) one thing it can do.

Programs and more: https://pandagardenio.github.io/robokids/web/phase-5-robots-that-learn/week-50-grand-finale-expo/
