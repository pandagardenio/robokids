🧠 Phase 5 · Robots That Learn

Week 47 AI Story Robot

⏱️ ~45 min build + short play sessions during the week 🎯 Skill: AI helps create

🧰 You need

  • Robot car
  • Laptop (parent uses an AI assistant)

🔧 Build together Together

  1. Kid invents a hero robot and a problem. Parent asks an AI for a 5-scene bedtime story with one robot action per scene.
  2. Edit the SCENES list in the code to match: each scene = a move + face + sound.
  3. Each A press plays the next scene while you read.

🎮 Play Kid time

Bedtime performance: you read, the robot acts.

💬 Talk about it Together

Which ideas came from you, and which from the AI?

⭐ Level up Kid time

Kid writes scene 6 alone.

💻 Load the program Grown-up job

Program: main.ts · needs the Cutebot extension

  1. Click the green 📋 Copy button on the program (below these steps).
  2. Go to makecode.microbit.org, click New Project and name it Week 47.
  3. Click Extensions at the bottom of the block list, search cutebot and click Cutebot.
  4. Click JavaScript at the top, select all the text (Ctrl+A, Mac: Cmd+A) and paste (Ctrl+V, Mac: Cmd+V).
  5. Click Blocks to see the colorful version your kid can change, then click Download.

First time, or something went wrong? See Start here.

📖 Words this week For grown-ups

Word What it means Say it to your kid
AI Artificial intelligence: a computer program that learns from examples instead of following rules someone wrote. A computer that learns by looking at examples.
AI assistant A chat tool like Claude or ChatGPT. At this age, the parent types and reads. A computer helper that writes words.
List A set of items in order. The program goes through them one by one. Like a shopping list for the robot.
Code Another word for the program: the instructions the robot follows. The robot's instructions.

Loading words like micro:bit, MakeCode, extension and Blocks are in the Start here word list. All words: glossary.
