🚗 Phase 3 · The Robot Car 🎉 Showcase week

Week 30 Showcase: Robot Olympics

⏱️ ~45 min build + short play sessions during the week 🎯 Skill: Review

🧰 You need

  • Robot car
  • Track, maze, parking spot from earlier weeks
  • Bottle-cap medals

🔧 Build together Together

  1. Load the menu program (steps below): A cycles through events, B starts.

🎮 Play Kid time

Three events: line race (timed), maze escape, parking. Family is the jury.

💬 Talk about it Together

Which event was hardest for the robot?

⭐ Level up Kid time

Invent a fourth event.

💻 Load the program Grown-up job

Program: main.ts · needs the Cutebot extension

  1. Click the green 📋 Copy button on the program (below these steps).
  2. Go to makecode.microbit.org, click New Project and name it Week 30.
  3. Click Extensions at the bottom of the block list, search cutebot and click Cutebot.
  4. Click JavaScript at the top, select all the text (Ctrl+A, Mac: Cmd+A) and paste (Ctrl+V, Mac: Cmd+V).
  5. Click Blocks to see the colorful version your kid can change, then click Download.

First time, or something went wrong? See Start here.

Draw this week's robot. Write (or dictate) one thing it can do.
