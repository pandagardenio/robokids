🚗 Phase 3 · The Robot Car

Week 24 Button Steering

⏱️ ~45 min build + short play sessions during the week 🎯 Skill: Events

🧰 You need

  • Robot car

🔧 Build together Together

  1. Load this week's program (steps below). A = turn left, B = turn right, A+B = forward, shake = stop.

🎮 Play Kid time

Slalom around shoes on the floor.

💬 Talk about it Together

How does the robot know which button was pressed?

⭐ Level up Kid time

Add a 'spin' move when you press the logo (V2 touch logo).

💻 Load the program Grown-up job

Program: main.ts · needs the Cutebot extension

  1. Click the green 📋 Copy button on the program (below these steps).
  2. Go to makecode.microbit.org, click New Project and name it Week 24.
  3. Click Extensions at the bottom of the block list, search cutebot and click Cutebot.
  4. Click JavaScript at the top, select all the text (Ctrl+A, Mac: Cmd+A) and paste (Ctrl+V, Mac: Cmd+V).
  5. Click Blocks to see the colorful version your kid can change, then click Download.

First time, or something went wrong? See Start here.

📖 Words this week For grown-ups

Word What it means Say it to your kid
Event Something that happens, like a button press or a shake, and the instructions that run when it does. When this happens, do that.
Accelerometer The sensor that feels movement: shaking, tilting, falling. It feels when you shake or tip the robot.
V2 The newer micro:bit, with a speaker, a microphone and a touch-sensitive logo. This project needs it. The newer micro:bit that can hear and talk.

Loading words like micro:bit, MakeCode, extension and Blocks are in the Start here word list. All words: glossary.
