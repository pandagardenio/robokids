📟 Phase 2 · micro:bit First Steps

Week 18 Rock, Paper, Scissors

⏱️ ~45 min build + short play sessions during the week 🎯 Skill: Random choice and if/else

🧰 You need

  • micro:bit + battery pack

🔧 Build together Together

  1. Load this week's program (steps below). Shake to make the robot choose.

🎮 Play Kid time

Play against the robot. Keep score on paper for the week.

💬 Talk about it Together

Can you predict what the robot will choose?

⭐ Level up Kid time

Add a fourth choice (lizard? spock?).

💻 Load the program Grown-up job

Program: main.ts

  1. Click the green 📋 Copy button on the program (below these steps).
  2. Go to makecode.microbit.org, click New Project and name it Week 18.
  3. Click JavaScript at the top, select all the text (Ctrl+A, Mac: Cmd+A) and paste (Ctrl+V, Mac: Cmd+V).
  4. Click Blocks to see the colorful version your kid can change, then click Download.

First time, or something went wrong? See Start here.

📖 Words this week For grown-ups

Word What it means Say it to your kid
Random Picked by chance, so nobody (not even the robot) knows what comes next. Like rolling a dice.
If / else The program checks something: IF it's true, do one thing, ELSE (otherwise) do another. If it rains, take an umbrella, else take sunglasses.

Loading words like micro:bit, MakeCode, extension and Blocks are in the Start here word list. All words: glossary.
