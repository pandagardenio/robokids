📟 Phase 2 · micro:bit First Steps

Week 16 Night-Light Robot

⏱️ ~45 min build + short play sessions during the week 🎯 Skill: Light sensor

🧰 You need

  • micro:bit + battery pack
  • Cardboard robot with a window

🔧 Build together Together

  1. Load this week's program (steps below). The LED screen is also a light sensor.
  2. Cover it with a hand: the robot lights up.

🎮 Play Kid time

Peekaboo: cover the robot's eyes to wake it up, uncover to put it to sleep.

💬 Talk about it Together

How can the same LEDs show light AND measure it?

⭐ Level up Kid time

Change how dark it must be before the robot wakes up.

💻 Load the program Grown-up job

Program: main.ts

  1. Click the green 📋 Copy button on the program (below these steps).
  2. Go to makecode.microbit.org, click New Project and name it Week 16.
  3. Click JavaScript at the top, select all the text (Ctrl+A, Mac: Cmd+A) and paste (Ctrl+V, Mac: Cmd+V).
  4. Click Blocks to see the colorful version your kid can change, then click Download.

First time, or something went wrong? See Start here.

📖 Words this week For grown-ups

Word What it means Say it to your kid
Sensor A part that lets the robot notice the world: light, heat, distance, sound, movement. The robot's eyes, ears and skin.
LED screen The 25 little lights on the front of the micro:bit that show pictures, numbers and letters. The robot's face.
Light sensor The micro:bit's LED screen can also measure how bright the room is. The robot's face can also see light.
LED A tiny light. It only works one way round: the long leg goes to plus (+). A tiny light that only works the right way round.

Loading words like micro:bit, MakeCode, extension and Blocks are in the Start here word list. All words: glossary.
