📟 Phase 2 · micro:bit First Steps 🎉 Showcase week

Week 20 Showcase: Robot Badge

⏱️ ~45 min build + short play sessions during the week 🎯 Skill: Review

🧰 You need

  • micro:bit + battery pack
  • Lanyard or safety pin + cardboard holder

🔧 Build together Together

  1. Combine favorite features: name scroll, pet face, dice.

🎮 Play Kid time

Kid wears the badge for a day and demos it to everyone they meet.

💬 Talk about it Together

Which feature do people like most?

⭐ Level up Kid time

Add their own idea to the badge.

💻 Load the program Grown-up job

Program: main.ts

  1. Click the green 📋 Copy button on the program (below these steps).
  2. Go to makecode.microbit.org, click New Project and name it Week 20.
  3. Click JavaScript at the top, select all the text (Ctrl+A, Mac: Cmd+A) and paste (Ctrl+V, Mac: Cmd+V).
  4. Click Blocks to see the colorful version your kid can change, then click Download.

First time, or something went wrong? See Start here.

✏️ Robot Journal Kid time

Draw this week's robot. Write (or dictate) one thing it can do.
