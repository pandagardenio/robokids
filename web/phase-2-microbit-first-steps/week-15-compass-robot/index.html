📟 Phase 2 · micro:bit First Steps

Week 15 Compass Robot

⏱️ ~45 min build + short play sessions during the week 🎯 Skill: Magnetic sensor

🧰 You need

  • micro:bit + battery pack
  • Paper with N, E, S, W drawn

🔧 Build together Together

  1. Load this week's program (steps below). First run asks to 'fill the screen' by tilting: that's calibration.
  2. The arrow always points north.

🎮 Play Kid time

Hide a toy north of the couch and give compass clues. Then switch roles.

💬 Talk about it Together

How does the robot know where north is without eyes?

⭐ Level up Kid time

Show the letter N, E, S or W instead of an arrow.

💻 Load the program Grown-up job

Program: main.ts

  1. Click the green 📋 Copy button on the program (below these steps).
  2. Go to makecode.microbit.org, click New Project and name it Week 15.
  3. Click JavaScript at the top, select all the text (Ctrl+A, Mac: Cmd+A) and paste (Ctrl+V, Mac: Cmd+V).
  4. Click Blocks to see the colorful version your kid can change, then click Download.

First time, or something went wrong? See Start here.

📖 Words this week For grown-ups

Word What it means Say it to your kid
Compass The micro:bit has a sensor that feels the Earth's magnetism, like a compass needle, so it knows where north is. It always knows which way is north.
Sensor A part that lets the robot notice the world: light, heat, distance, sound, movement. The robot's eyes, ears and skin.
Accelerometer The sensor that feels movement: shaking, tilting, falling. It feels when you shake or tip the robot.
Calibration Setting up a sensor so it measures correctly. The compass asks for it the first time. Teaching the sensor where things are.

Loading words like micro:bit, MakeCode, extension and Blocks are in the Start here word list. All words: glossary.
