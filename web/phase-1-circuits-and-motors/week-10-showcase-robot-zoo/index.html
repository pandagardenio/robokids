💡 Phase 1 · Circuits and Motors 🎉 Showcase week

Week 10 Showcase: The Robot Zoo

⏱️ ~45 min build + short play sessions during the week 🎯 Skill: Review

🧰 You need

  • Everything built so far
  • Phone for filming

🔧 Build together Together

  1. Set up a 'zoo' on the table with name cards for each robot.
  2. Kid picks a favorite and fixes or improves it.

🎮 Play Kid time

Kid gives a one-minute tour you film. Send it to family.

💬 Talk about it Together

Which robot was hardest to build? Which was most fun?

⭐ Level up Kid time

Invent a new animal robot from the parts you have.

✏️ Robot Journal Kid time

Draw this week's robot. Write (or dictate) one thing it can do.

Programs and more: https://pandagardenio.github.io/robokids/web/phase-1-circuits-and-motors/week-10-showcase-robot-zoo/
